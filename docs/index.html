Un chat que
se autodestruye solo.

Un comando, cero login, cero cuenta que borrar después. wrangler deploy --temporary levanta el chat en segundos sobre una cuenta de Cloudflare desechable que dura ~1 hora y desaparece sola — Worker, mensajes y todo.

Por qué existe

No todo chat necesita vivir para siempre

A veces solo hace falta un lugar para coordinar algo puntual: una llamada, un evento, un grupo de prueba. Crear cuenta, configurar, y después acordarte de borrarlo es fricción que no aporta nada.

⚡

Cero fricción

Sin crear cuenta, sin login, sin tarjeta. Un comando y tenés una URL pública funcionando.

🧹

Se limpia solo

Nada que recordar borrar. Pasada la hora, Cloudflare elimina la cuenta temporal y todo lo que contiene.

🔐

Privado por diseño

Modo cerrado con invitaciones de un solo uso si necesitás que entre solo gente específica.

Funcionalidades

Lo justo para un chat de verdad

Construido sobre un único Durable Object por sala: WebSockets en vivo + SQLite para el estado.

💬

Tiempo real

WebSockets vía la Hibernation API de Durable Objects — hasta miles de conexiones por sala.

🗂️

Historial persistente

Los últimos 50 mensajes se guardan en SQLite del propio Durable Object. Quien entra tarde los ve.

🎨

Identidad por mensaje

Nombre y color por usuario, burbujas propias vs. ajenas, todo escapado (sin XSS).

🔓

Abierto o cerrado

Cualquiera con el link, o solo invitados con links de un solo uso generados por el admin.

👑

Rol admin

El primero en conectar con ?admin=1 controla la sala y guarda un link para volver a entrar.

📱

Mobile-first

Pantalla completa en celular, input pegado abajo, sin barras raras de zoom.

Cómo funciona

De cero a chat en menos de un minuto

Cloná el repo

No hace falta tener cuenta de Cloudflare ni estar logueado.

git clone https://github.com/MauricioPerera/wrangler-ephemeral-chat.git cd wrangler-ephemeral-chat && npm install

Desplegá con --temporary

Wrangler crea una cuenta desechable, despliega el Worker y te da la URL pública.

npx wrangler deploy --temporary

Compartí el link

Mandale la URL del chat a quien quieras. El chat vive mientras viva la cuenta temporal (~1 hora).

¿Te gustó? Quedátelo

Wrangler también te da una claim URL. Abrila y logueate antes de que venza la hora y el Worker pasa a tu cuenta real, para siempre. Si no hacés nada, se borra solo.
